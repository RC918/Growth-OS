# 成長機會來源與審核證據鏈｜測試工作台

## 交付

- 工作台每張機會卡片可展開來源種類、觀察時間、來源說明，以及審核決策、理由與時間。來源網址僅以純文字呈現，避免把未審核的網址做成可點擊連結。
- owner 與 viewer 均只能透過現有 RLS 讀取所屬工作區的來源與決策；瀏覽器沒有資料表的直接寫入權限。
- 缺少來源，或已核准／拒絕卻沒有對應決策時，工作台明示資料缺口。達到查詢筆數上限會報錯，不會把截斷結果偽裝成完整證據。
- 未接入 GSC／GA4，搜尋曝光、到站訪問與商業成果均顯示未知，不產生憑空的流量排名。

## 驗證

- 本地 Workspace API 測試驗證 owner 與 viewer 來源／決策查詢皆限定所屬工作區，並檢查預覽與原型檔案一致。
- 獨立 Supabase 測試專案可見合成來源及決策，`authenticated` 對兩表具有 SELECT grant，兩表已有 RLS 讀取政策。
- 2026-09-29 晚上以真實 owner 測試帳號進入獨立 Vercel 預覽的測試工作台。驗收截圖可見 owner 工作區、三張合成機會卡片，以及展開後每張卡片的來源種類、觀察時間、來源說明、審核結果、審核時間與理由。這完成了新版預覽的 owner 網頁端到端顯示驗收；截圖僅證明合成測試資料的呈現，不代表已核實真實流量或商業成果。

本階段沒有建立正式網域、接入真實商家資料、發布內容或修改付費設定。下一項工程為排序規則與內容版本紀錄，須以可核查的來源和人工決策為基礎。
