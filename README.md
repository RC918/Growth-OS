# Growth OS

Growth OS is an early-stage commerce growth product by Good Morning Digital Co., Ltd. The repository holds a public landing-page audit prototype, an offline measurement proof, and design documents. The product name and domain remain working decisions.

Development status: prototype. No customer site, GA4, GSC, advertising account, payment system, or production service is connected.
