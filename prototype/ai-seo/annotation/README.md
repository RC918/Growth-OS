# 文案證據審閱頁（本機離線版）

這是一個不需要登入、不需要任何帳號的靜態審閱頁面，供非技術背景的審閱者
判斷 AI 文案是否符合來源證據。

## 審閱者如何進入

1. Owner 將 `review.html` 這一個檔案傳給審閱者（不得公開部署或上傳到公開網站）。
2. 審閱者直接用瀏覽器開啟該檔案即可開始，不需要 GitHub 帳號或任何權限。

## 如何使用

1. 在頁首填寫自己的審閱者代號（例如 A、B），先讀頁首的「判斷準則」。
2. 畫面一次只顯示一題，以繁體中文為主要閱讀內容；英文原文收在
   「英文原文（參考）」中，需要時再展開。用「上一題／下一題」移動，
   選擇「正確／錯誤／無法判定」並用一句話寫下理由。代號、目前題號
   與進度會自動保存在該台裝置的瀏覽器中，刷新或關閉後用同一瀏覽器
   開啟即可接續。若瀏覽器不保存進度，頁首有「備份進度檔／還原
   進度檔」，可把進度存成檔案、下次載入續填，不需任何技術操作。
3. 30 題完成後，按「下載我的審閱結果 (CSV)」，把檔案交回 Owner。
   兩位審閱者必須各自獨立填寫、下載，不要互相討論。

## 版本說明

目前頁面使用題目版本 v2：證據片段已補全為可信來源的完整句子
（盤點見 `docs/Phase3B2_Evidence_Audit_2026-10-22.md`），文案與題號
不變。v1 已回收的審閱結果屬 v1 標註、完整保留；新版頁面會自動
接續審閱者在舊版已填寫的答案。

## 結果如何回收與裁決

- 回收的 CSV 以 `case_id`（h01–h30）對應原案例，欄位為判定與理由。
- 裁決者在頁面下方的「裁決者專用」區選取兩位審閱者的 CSV，
  系統只列出判定不同的題目；裁決後可下載裁決紀錄 CSV。
- 完整回收、裁決與凍結後比較流程見
  `docs/Phase3B2_Annotation_Return_And_Adjudication_2026-10-21.md`。

## 重新產生頁面

盲標資料更新後（目前讀取 v2 盲審包與 v2 翻譯檔），在 repo 內執行
`node prototype/ai-seo/annotation/build-review-page.mjs` 即可重建 `review.html`。
產生器只讀取盲標包，不讀取工程標籤或 Prototype 輸出。
